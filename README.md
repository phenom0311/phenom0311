# 주현상 | Backend / Infrastructure Portfolio

Backend와 Infrastructure를 함께 이해하는 개발자로 성장하고 있습니다.

웹, AI 프로젝트 경험을 바탕으로 최근에는 **백엔드 API**, **AI 추론 서버 연동**, **GPU 실행 환경**, **서비스 실행 문서화**에 관심을 넓히고 있습니다. Infrastructure는 본격적으로 배우기 시작한 분야이지만, Linux/WSL, SSH, Slurm 환경에서 직접 모델 학습과 GPU 자원 관리를 경험하며 운영 관점의 개발을 공부하고 있습니다.

## 먼저 봐주시면 좋은 프로젝트

### 1. 전남 미리콜

[전남 미리콜 GitHub](https://github.com/jeonnam-miricall)

전남 농어촌 및 도서산간 지역의 고령자와 이동 취약자를 위한 AI 기반 재난 대응 서비스 프로토타입입니다. AI 안심콜, 위급 음향 감지, GIS 기반 대피 경로 안내를 결합했습니다.

**역할**

- 4인 팀 팀장
- 위급 음향 모델 학습 및 평가 실험
- STT/LLM/TTS 기반 음성 흐름 검증
- GPU 서버 실행 환경 관리
- SSH, Slurm, ngrok, Render 기반 데모 운영 흐름 정리
- 백엔드와 AI 서버 간 API 계약 및 실행 문서 정리

**설명 가능한 키워드**

- Express + TypeScript API
- Python/FastAPI 기반 AI 서버
- PyTorch 모델 학습 및 평가
- GPU 서버, SSH, Slurm 작업 실행
- 환경변수와 비밀값 분리
- 데모 운영 문서화

### 2. 데이터분석기초 강의 챗봇

[2023-Daebungi-Chatbot/main](https://github.com/2023-Daebungi-Chatbot/main)

데이터분석기초 강의에서 조교 4명이 함께 만든 강의 지원용 챗봇 프로젝트입니다.

**설명 가능한 키워드**

- 강의 운영 맥락에서 필요한 챗봇 기능 정리
- 팀 단위 개발과 저장소 관리
- Python 기반 챗봇/데이터 처리 흐름 학습

### 3. Class Bridge

Class Bridge는 교사가 가진 수업 자료를 AI가 분석해 학습 장벽을 진단하고, UDL 관점의 수업 재구성 방향과 보조 자료 초안을 제안하는 Next.js 기반 개인 프로토타입입니다.

**설명 가능한 키워드**

- Next.js App Router
- TypeScript
- API Route
- Gemini API 연동
- Zod 기반 AI 응답 검증
- 단계별 결과 확인 UI
